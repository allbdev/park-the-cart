# Designs

Exports of the boards on the design canvas **"Estacione o Carrinho — Mockups"**: https://claude.ai/artifact/1saXC69MKJ1wjoqMoXJwCa. Reference only, not used in the game.

The canvas, these files, `GAME_PLAN.md` and the game are kept in sync both ways (see `CLAUDE.md`).

The screens (01–09) are drawn mockups for now. Once the game exists they are replaced by captures from the real game (`npm run designs`, roadmap Phase 6), PT-BR here and English in `en/`. The text boards (10–12) are edited by hand on the canvas and exported.
